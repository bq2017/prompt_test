# Evidence-15 V9 Stage5.2-B 实验协议

## 实验问题

在冻结的 Stage5 Compact 原始4档预测中，严格、独立的B审计器能否以
足够高的边际精度和重复稳定性救回教师5档，同时控制所有非5档题的误升？

## 冻结项

- Stage5 Compact Prompt不修改。
- S标签等于Stage5 Compact原始模型档位。
- B只接收原始4档候选。
- B不接收Stage5理由、Stage5特征、教师标签或教师理由。
- T只允许确定性的4→5。
- 原自动4→5后处理保持`audit-only`。
- 三次运行之间不得修改Prompt、schema、候选提取器或映射器。

## B触发

B必须同时通过：

1. 同一最高难任务；
2. 非常规现场中间模型M；
3. 两个不同且不可约的高阶因果功能X、Y；
4. 不可独立求解后拼接，且不是单一卡点后的机械长尾；
5. 删除X或Y都会破坏共同目标的闭合。

触发值由`chemistry_stage52_b_schema.py`确定性计算。模型不得直接声明最终
难度或`composite_burden`。

## 指标定义

`B新增非5`包含教师1、2、3、4档。

```text
B边际精度 = B新增教师5 / B新增总数
B协议净收益 = B新增教师5 - B新增所有非5
```

另行报告：

- 教师4→5；
- 教师≤3→5严重误升；
- B新增题平均绝对误差变化；
- S/T Accuracy、MAE、教师4召回、教师5召回和预测5精度；
- 每题三次触发0/1/2/3次的稳定性。

## 验收

### B机制

- 三次协议净收益均为正；
- 多数触发集合边际精度不低于70%；
- 每次有效审计覆盖率不低于98%；
- 每次教师4召回相对同次S下降不超过3个百分点；
- 稳定救回教师5多于稳定误升所有非5。

### Stage5.2整体候选

- 平均教师5召回不低于30%；
- 平均预测5精度不低于65%；
- 三次T Accuracy均高于同次S；
- 三次T MAE均不高于同次S；
- 另与Stage4原始三次均值Accuracy 61.5905%、MAE 0.408023比较。

B机制与整体候选分别验收。任一结论不得替代另一结论。
