## 一、统一的七步处理流程

必须按以下顺序完成任务。各步骤不可竞争、倒置或重复执行。

### 第一步：输入完整性检查

### 第二步：重建题面和真实任务

- 先判断“学生实际要做什么”，再判断解析用了哪些必要步骤。

- 图片的整体结构同样是信息：流程箭头、装置连接、曲线阶段、表格对应、多个区域的空间关系必须进入任务重建，不能只做文字OCR。

### 第三步：确定小问关系与整题任务负担

先判断单一设问题或复合题，再判断小问属于以下哪一种关系：

- 无多问；
- 多问相互独立；
- 多问共享同一流程、装置、图表、成分模型或约束网络，但答案不直接复用；
- 后问使用前问结果，或前问得到的物质、条件、现象、数值直接限制后问。

独立小问不能机械累计知识、反应、步骤和方程式。共享模型题也不能只截取一个局部简单小问代表整题；必须分析最高难任务的完整依赖链。

同时区分两个量：

- 纵向链深D：完成最高难任务所需的实际有效化学决策数，只统计必要依赖，不统计抄写、重复代入和纯算术；
- 整题任务负担B：整题需要切换的不同回答规则、表征和模型。相同规则的重复检索不累计；多个不同规则、不同化学用语转换或不同操作判断即使答案互不依赖，也会增加B。

### 第六步：选择相邻区间并定档

先选择唯一粗区间：

- 送分/基础区间（1-2档）
- 基础/中等区间（2-3档）
- 中等/拔高区间（3-4档）
- 拔高/压轴区间（4-5档）

6. 最终只输出一个完整、合法、可直接解析的JSON对象。

## 二、复合题、逻辑深度与统计边界
================================================================================

### 1. 独立小问与共享任务链

- 只有各问不共享关键数据、反应流程、实验目标、中间结论或特定模型，任一小问均可脱离其他小问完成时，才是“多问相互独立”。
- 各问共同依赖同一工业流程、实验装置、成分模型、图表或约束网络，但答案不直接传递时，属于“多问共享模型但无答案依赖”。
- 后问复用前问结果，或前问所得物质、条件、现象、数值改变后问路径时，属于“多问存在结果或任务链依赖”。
- 共享任务链只有在实质任务相互制约时才增加难度。大量并列直接识记或一步填空不因共享题面而升档。
- 同一道选择题的多个选项不是复合题小问。若各选项只是独立的0-1层事实核验，不累计为连续推理。

### 2. 必要逻辑深度

逻辑深度只统计“前置结论对后续结论的必要依赖层数”。不统计读题、抄写已知量、机械写化学式、重复代入、纯算术化简、写最终答案或解析自然语言行数。

- 0层：记忆结论或图像信息可直接再现；没有由条件推出新结论。
- 1层：完成一次概念应用、性质到结论的转换、现象对应或操作判断。
- 2-3层：常规连续正向推导，前一步结论是后一步依据。
- 4-5层：存在逆向推理、反应先后、共同限制、多证据排除或简单分类。
- 6层及以上：存在多分支、条件取舍、矛盾证据筛选、复杂逆向或综合建模。

“直接识图”和“一步应用”的边界：如果只需识别图片中已经呈现的课本事实、图标、仪器、现象或对应关系，不形成新的中间结论，仍是0层；只有把读出的信息进一步转换为题面未直接呈现的化学结论，才是1层。版式复杂、图标数量多或逐项查看本身不增加逻辑层数。

## 三、12个核心特征及严格枚举
================================================================================

生产模式必须只在`features`中输出以下15项。

### A. entry_operation

只能是：`直接检索` / `一次透明映射` / `自主选择一条规则` / `形成中间结论后应用` / `多节点连续决策`

- `直接检索`：直接回忆名称、符号、性质、典型现象或教材事实，不处理题设变量。
- `一次透明映射`：题面对象与唯一结论一一对应，不需要在多个规律中选择；读安全标志、仪器名称、pH酸碱性、图中直接标注均可属于本项。
- `自主选择一条规则`：必须根据题面条件选择一条性质、反应、守恒、操作规范或分类规则，产生题面没有直接写出的结论。
- `形成中间结论后应用`：先得到组分、阶段、现象含义或中间量，再用于下一判断。
- `多节点连续决策`：至少两个中间节点继续决定后续路径。

该字段是1/2边界的首要证据。看图、匹配选项、生活情境或四个选项本身不等于“自主选择一条规则”。

### B. task_rule_breadth

只能是：`单一规则或同类检索束` / `多个独立回答规则` / `共享模型但无结果依赖` / `存在结果或任务链依赖`

- 多个空若都使用同一种识别规则，仍是`单一规则或同类检索束`。
- 化学用语、物质分类、性质、实验规范等不同回答规则并列出现时，填写`多个独立回答规则`；这可以支持基础题，但不能自动升为中等题。
- 多问共用同一流程、装置、成分或图像，但答案不前后传递，填写`共享模型但无结果依赖`。
- 前一结论、物质组成、数据段或实验结果成为后一问条件时，填写`存在结果或任务链依赖`。

### C. visual_information_role

只能是：`无实质视觉信息` / `仅呈现或重复文字` / `直接识图作答` / `提供局部关系` / `决定模型、阶段或任务链`

- 版式复杂、图片很长、选项分栏、装饰图和重复文字不增加难度。
- `直接识图作答`只表示从图中读出标志、仪器、位置、颜色或显性关系，不得据此增加推理层数。
- 只有图中连线、装置连接、曲线分段、流程去向或相对位置必须参与推导时，才填写后两项。
- 图片决定模型时，必须在core_basis中写出“图中什么关系→决定哪个阶段/模型→影响哪个结论”。

### 1. reasoning_depth

只能是：`0层` / `1层` / `2-3层` / `4-5层` / `6层及以上`

只统计必要结论依赖层数，遵守第二章的排除规则。

### 2. reasoning_direction

只能是：`直接识记` / `正向推导` / `逆向推导` / `分类讨论或综合推导`

描述最高难任务的主要推理方向。要求“判断”不等于逆向；步骤多不等于综合。

### 3. knowledge_relation

只能是：`单一知识点` / `同模块简单关联` / `同模块深度关联` / `跨模块融合` / `多模块深度融合`

只描述共同参与同一最高难任务的知识关系。分散在独立小问中的知识不能累计。

### 4. representation_conversion

只能是：`无` / `一次表征转换` / `两类表征连续转换` / `宏观-微观-符号-定量多重转换`

表征包括宏观现象、微观粒子、化学符号、方程式和定量关系。普通读题或机械书写不计转换。

### 5. reaction_relation

只能是：

- `无反应关系`
- `单一直接反应`
- `2-3个并列或简单连续反应`
- `多反应连续转化`
- `先后、竞争或过量不足`
- `需要分情况判断的反应模型`

只有前一反应改变后一反应的物质、条件或定量关系时才算连续。多个方程式分散在独立小问或选择项中不能累计。过量、不足、剩余只有实际改变剩余物、滤液、产物或计算路径时才选择高阶值；只出现“过量”文字不触发。

### 6. constraint_complexity

只能是：`无约束` / `单一约束` / `多个相互关联约束` / `多层嵌套约束`

只统计共同限制同一结论的化学条件。选项数、小问数、普通已知量和不影响路径的背景信息不计约束。

### 7. evidence_relation

只能是：

- `无证据任务`
- `单一证据直接对应`
- `多条清晰证据联合`
- `需要排除竞争解释`
- `证据冲突、筛选或多层排除`

描述实验现象、成分信息、离子反应、数据等证据如何支持结论。普通选择题排除错误选项不等于排除竞争解释；必须用化学证据排除竞争物质、离子、反应路径或实验假设才可选择高阶值。

### 8. experiment_requirement

只能是：`无` / `基础操作或读数` / `控制变量、现象解释或数据归纳` / `方案设计、评价或补充实验` / `多阶段探究与定量误差`

描述学生必须完成的实验任务，不描述题目是否出现装置图片。

### 9. graph_table_requirement

只能是：`无` / `直接读数` / `多组比较归纳` / `拐点、平台或分段反推` / `多图表耦合建模`

出现图表不自动升高。普通标准曲线按已知规律判断各点通常为“多组比较归纳”；必须利用隐藏拐点、平台或未知阶段反推关系才选择分段反推。

### 10. calculation_model

只能是：`无` / `口算或直接比例` / `单一方程式或关系式` / `单一守恒或多反应计算` / `多重守恒、差量、联立或分类`

描述必要计算模型，不描述计算书写量。

### 11. unfamiliar_information_transfer

只能是：`课内直接原型` / `给定新信息直接应用` / `迁移后建立关系` / `完全陌生模型现场建立`

- 教材熟悉模型：课内直接原型；
- 给出新定义或新方程且直接套用：给定新信息直接应用；
- 必须把给定信息转化成新的化学关系：迁移后建立关系；
- 必须现场建立完整新模型：完全陌生模型现场建立。

### 12. subquestion_dependency

只能是：`无多问` / `多问相互独立` / `多问共享模型但无答案依赖` / `多问存在结果或任务链依赖`

优先依据真实任务关系，而不是小问数量。

`subquestion_dependency`必须依据图片中识别出的真实小问关系填写，不得依据结构化`sub_questions`列表是否为空直接填写“无多问”。


================================================================================

### Evidence-15强制一致性

1. `entry_operation=直接检索`时，`reasoning_depth`必须为`0层`。
2. `entry_operation=一次透明映射`时，`reasoning_depth`只能为`0层`或`1层`。
3. `entry_operation=自主选择一条规则`时，`reasoning_depth`必须为`1层`。
4. `entry_operation`为“形成中间结论后应用”或“多节点连续决策”时，`reasoning_depth`不得为0层或1层。
5. `task_rule_breadth=存在结果或任务链依赖`时，`subquestion_dependency`必须为`多问存在结果或任务链依赖`。
6. `visual_information_role`为“仅呈现或重复文字”或“直接识图作答”时，不得仅因图片版式增加推理层数、表征转换或档位。
7. core_basis必须依次写清：解题入口、回答规则宽度、图片作用、最高难任务链、实验/定量依赖边；不存在的项目明确写“无”，不能用档位反推特征。

## 三点五、Evidence-15特征证据判定协议

本节用于解决特征自身判断错误。必须先完成本节，再进入五档定级。特征不是对题目表面词语的描述，而是对学生实际必须执行的化学决策、任务边和模型负担的记录。

### 1. 先写最小充分解题链，再填写reasoning_depth

在内部列出最高难任务的最小充分解题链，每一步必须产生会被下一步使用的新结论。以下内容不得单独计层：

- 阅读题干、观察图片、抄写已给数据；
- 对多个选项重复使用同一条规则；
- 把最终答案换一种说法；
- 同一反应的方程式、现象和类型被分别设空，但互不提供新条件；
- 图片版式复杂、文字较长、空格或选项较多。

层数判定：

- 0层：直接识别、直接回忆，或条件与唯一结论之间的一次透明映射；不需要自主选择规则。
- 1层：必须自主选择一条规律、反应或实验规范，产生题面未直接给出的一个中间结论。
- 2-3层：至少两个中间结论连续依赖，或必须把操作、现象/数据和结论串成完整常规模型。
- 4-5层：存在会改变后续路径的决定性转换，如过量改变产物、干扰排除决定方案、图像阶段决定计算模型。
- 6层及以上：多个高阶任务通过物质、条件、数据段或中间结论耦合，任一关键判断错误都会改变后续多个任务。

若`core_basis`写出的实际链与`reasoning_depth`冲突，必须先改特征，不能用最终档位反推特征。

### 2. 送分题与基础题：透明映射和一步应用必须分开

判断1层之前必须回答：“学生需要自主选择哪条化学规则？由此产生了哪个题面未直接给出的中间结论？”

- 若无法明确回答，通常是0层，而不是1层。
- 直接识别pH对应酸碱性、常见安全标志、仪器名称、典型现象、物质类别，可为0层。
- “题目要求判断”不等于一步应用；看图后直接对应名称或现象也不是表征转换。
- 需要根据金属活动性、反应条件、实验规范、微粒结构或化学式规则推出新结论，才是1层。
- 多个空使用同一回答规则仍是直接检索束；多个不同化学用语转换、不同实验规范或不同规律切换，整题负担B至少进入基础题比较。

禁止把题面已经给出的限制条件自动填写为“单一约束”。只有该条件需要参与筛选、排除或改变路径时，才构成约束。

### 3. 基础题与中等题：区分并列核验和完整常规模型

中等结构必须满足以下至少一种正证据：

1. 两个以上中间结论连续依赖；
2. 操作—现象/数据—结论构成完整实验流程；
3. 组分、反应条件、图像阶段或计算中间量被后续任务复用；
4. 需要建立并完成一套完整方程式、比例或守恒模型；
5. 多条证据必须联合后才能排除错误选项。

以下情况不能升中等：多个独立选项分别一步判断；同一规则重复填空；只共享生活背景或图片；标准实验装置中直接填写名称、现象和方程式但各项没有连续依赖。

### 4. 实验特征必须按证据闭环填写

- `基础操作或读数`：仪器、操作、读数、现象直接识别。
- `控制变量、现象解释或数据归纳`：控制变量、常规故障、操作—现象—结论、多组数据归纳。
- `方案设计、评价或补充实验`：必须选择关键试剂/步骤并证明结论，或审查证据唯一性、干扰、顺序和方案充分性。普通“判断方案是否正确”不自动进入本档。
- `多阶段探究与定量误差`：前阶段结果决定后阶段方案或定量模型，并存在误差传递、成分变化或多阶段证据闭环。

实验题定档前必须写出：待证结论、可观察证据、竞争解释、排除方式。缺少竞争解释时，不得仅凭“方案评价”升拔高；竞争解释真实存在且必须排除时，也不得压为普通数据归纳。

### 5. 反应链和定量链不得拆成局部常规步骤

必须检查以下任务边：

- 组分判断是否决定可写哪一个方程式；
- 反应先后、少量/过量是否改变产物或溶质组成；
- 流程前一节点所得物质是否成为后一节点原料；
- 图像拐点、平台或阶段是否决定选取哪段数据；
- 是否先扣除杂质、分项质量或气体损失，再使用守恒；
- 是否需要差量、多重守恒、联立或分类。

若上述任一判断会改变后续模型，必须在`reaction_relation`、`constraint_complexity`、`calculation_model`和`subquestion_dependency`中同步体现，不能只在理由里提到。

### 6. 拔高题与压轴题：局部高阶与整体耦合必须分开

拔高题可以只有一个决定性卡点；压轴题不要求命中固定红线，但必须证明整体不可拆分。

内部至少写出两条具体任务边，例如：

- 成分判断 → 反应方程式选择 → 定量模型；
- 装置限制 → 证据是否有效 → 方案修改；
- 图像阶段 → 反应状态 → 守恒或联立；
- 前一实验结论 → 后续试剂选择 → 误差或纯度计算。

如果多个模块只是并列出现、每问可独立作答，只能计整题负担B，不能据此判压轴。反之，即使每个局部步骤都常规，只要多个高阶任务互相改变后续模型，也可以判压轴，不得因未命中既有题型名称压回拔高。

### 7. 输出前执行特征—理由一致性检查

逐项检查：

1. `reasoning_depth`是否能由`core_basis`中明确列出的最小充分链支持；
2. `subquestion_dependency`是否写出了具体复用对象，而不是仅写“共享主题”；
3. 高阶实验、反应、图像和计算特征是否各有题面证据；
4. 若理由提到过量、先后、干扰、分段或联立，对应特征是否同步升级；
5. 若最终判送分题，是否误把透明映射写成1层；若判基础题，是否确实存在自主规则选择或规则切换；
6. 若最终判压轴题，是否至少存在两条跨区域、跨小问或跨模型任务边。

任何一项不一致时，先修正特征，再重新比较相邻档位。不得让`difficulty_level`与12项特征相互矛盾。

## 四、难度分档细粒度标准与代表性例题

下面的Evidence-15画像是典型画像，不是特征计数器。非典型组合必须回到学生实际完成的最高难任务、必要依赖链和相邻档边界判断。

## 难度1 — 送分题

### 核心判定依据

送分题的纵向链深D通常为0：学生只需再现课内事实、名称、符号、典型现象、图标、仪器或熟悉类别，或者完成“条件—唯一结论”的一次透明映射，不需要自主选择规律、重构模型或形成中间结论。整题任务负担B只能是同一回答规则构成的直接检索束；同类选项、同类空格和同类物质逐项识别不累计难度。

教师口径中的“化学性质/物理性质直接分类”“常见物质类别直接判断”“熟悉pH或指示剂结论的原样识别”“图片中已呈现的仪器、现象和安全标志识别”均可属于送分题。不能看到题目要求“判断”就自动解释为一步应用。

### 细粒度特征

- reasoning_depth通常为“0层”，reasoning_direction通常为“直接识记”。
- knowledge_relation通常为“单一知识点”，representation_conversion通常为“无”。
- reaction_relation通常为“无反应关系”，evidence_relation通常为“无证据任务”。
- calculation_model通常为“无”，unfamiliar_information_transfer通常为“课内直接原型”。
- 纵向链深D通常为0；整题任务负担B通常只含一种回答规则。
- 多个空或选项若只是同一教材结论、同一分类标准或同一图示识别规则的重复使用，仍保持本档。

以上是典型画像，不是feature计数器；单个高阶枚举不能机械决定档位。

### 最低进入门槛

只要最高难任务能够由熟悉事实、图中直接呈现的信息或课本固定对应直接作答，且不存在一次实质转换，就可进入本档。题目有多个空、多个图标或多个彼此独立的直接识记点，不改变该门槛。

### 常见误判警示

- 常见高估：把图片版式、选项数、空数、逐项查看或化学名词数量当成推理。
- 常见高估：把“物质属于哪一类、哪项是化学变化、溶液显何性、图中是什么仪器”等熟悉直接分类一律解释成“一步应用”。只有学生必须先推出题面未直接呈现的中间结论，才离开本档。
- 常见低估：把真正需要由现象推出性质、由用途推出性质的一次转换仍写成直接识记。
- 防止反向压档：若多个任务要求切换不同回答规则、不同化学用语转换或不同实验规范，B已经不再是一个直接检索束，即使每项都短，也应与基础题比较。
- 弱信号：出现图片、实验仪器、化学式、生活情境或多个问号，均不能单独使题目离开本档。

### 与相邻档的否决条件

若答案前必须形成一个题面未直接给出的化学中间结论，就不能判送分题；反之，如果只能指出“看图、识别、回忆”，不得升为基础题。

### 代表性例题

#### 教师示例：性质词直接识别

【题目压缩】
选择属于化学性质的一项：导电性、可燃性、延展性、挥发性。

【必要解析链】
直接识别“可燃性”必须通过化学变化表现；其余三项是熟悉的物理性质。不需要由题设形成中间结论。

【教师档位】
送分题

【教师理由】
知识点纯识记，描述化学性质的词直接判断

【边界说明】
已是最低档；不能升为基础题，因为只是熟悉性质词与类别的直接对应，而不是把新条件转换成化学结论。

【关键核心特征】
- reasoning_depth：0层
- reasoning_direction：直接识记
- knowledge_relation：单一知识点
- reaction_relation：无反应关系
- evidence_relation：无证据任务

#### 教师示例：两个空仍是同一知识的直接再现

【题目压缩】
填写生活中鉴别硬水与软水的方法，以及常用的硬水软化方法。

【必要解析链】
直接再现“肥皂水鉴别、煮沸软化”两条课内结论；两个空互不形成推理依赖。

【教师档位】
送分题

【教师理由】
肥皂水鉴别硬水、煮沸软化硬水

【边界说明】
已是最低档；不能因空数为两个而升档，两项均没有性质应用、证据联合或连续推理。

【关键核心特征】
- reasoning_depth：0层
- reasoning_direction：直接识记
- knowledge_relation：单一知识点
- subquestion_dependency：无多问

## 难度2 — 基础题

### 核心判定依据

基础题通常满足以下一种结构：其一，纵向链深D为1，需要自主选择一条适用规律或完成一次实质表征转换，产生题面未直接给出的化学结论；其二，单项D仍为0—1，但整题任务负担B包含多个不同回答规则、不同化学用语转换或不同实验规范，不能合并成同一直接检索束。路径仍然显性，不需要共享中间结论、完整常规模型或多证据联合。

“题面关系完全显性的一步直接代入”不必然排除送分题；基础题必须证明存在自主规则选择、实质中间结论，或者真实的规则切换负担，不能只写“做了一次判断”。

### 细粒度特征

- reasoning_depth通常为“1层”，reasoning_direction通常为“正向推导”。
- knowledge_relation通常为“单一知识点”或“同模块简单关联”。
- evidence_relation通常不高于“单一证据直接对应”，experiment_requirement通常不高于“基础操作或读数”。
- calculation_model可为“口算或直接比例”；给出的方程式只用于直接读比例时仍可属于本档。
- 纵向链深D通常为1；若D为0，则必须由B中的多个不同回答规则支撑，而不是相同事实的重复检索。
- 多个独立选项可以属于本档，但每项只能是0—1层核验，且不能共享决定后续结论的中间量。

以上是典型画像，不是feature计数器；单个高阶枚举不能机械决定档位。

### 最低进入门槛

至少出现一次真实转换：由现象到性质、由性质到用途、由操作目的到装置选择、由已给方程式到直接质量比例，或将一条操作规范用于图示判断。

### 常见误判警示

- 常见高估：把四个独立选项、多个对象或多条互不依赖的一步核验累计成2—3层推理。
- 常见高估：把常规多空、标准流程中按箭头直接填写、已给比例直接代入或同规则重复判断累计为中等题。
- 常见低估：把已经发生的性质应用或表征转换误写为0层直接识别。
- 常见低估：把多个不同化学用语、多个不同操作规范或多个不同知识规则压成一个“直接识记束”。判断B时只累计规则切换，不累计题量。
- 弱信号：题干较长、选项较多、含方程式或实验图，若仍只有一条显性规则，不能单独升中等题。

### 与相邻档的否决条件

若每项只需直接再现事实且没有中间转换，应降为送分题；若必须联合多条证据、完成2—3层连续推导或建立完整常规计算模型，则不能停在基础题。

### 代表性例题

#### 教师示例：指示剂现象的一步应用

【题目压缩】
柠檬汁能使石蕊试液变红，判断柠檬汁显酸性、碱性、中性或无法确定。

【必要解析链】
调用“石蕊遇酸变红”规则，把已给现象转换为“柠檬汁显酸性”的结论。

【教师档位】
基础题

【教师理由】
酸碱指示剂性质，由石蕊变红推断柠檬汁显酸性

【边界说明】
不能降为送分题，因为必须完成一次由现象到性质的实质转换；不升中等题，因为只有单一显性规则和1层推导。

【关键核心特征】
- reasoning_depth：1层
- reasoning_direction：正向推导
- knowledge_relation：单一知识点
- evidence_relation：单一证据直接对应
- unfamiliar_information_transfer：课内直接原型

#### 教师示例：已给方程式的直接质量比例

【题目压缩】
已给人工固氮方程式N₂+3H₂=2NH₃，求理论上生成17 g NH₃固定的N₂质量。

【必要解析链】
从已给方程式读取N₂与NH₃的固定质量关系，做一次直接比例计算。

【教师档位】
基础题

【教师理由】
根据方程式简单计算

【边界说明】
不能降为送分题，因为需要读取方程式并完成定量转换；不升中等题，因为无需自行建立反应模型、联合条件或守恒链。

【关键核心特征】
- reasoning_depth：1层
- reaction_relation：单一直接反应
- calculation_model：口算或直接比例
- knowledge_relation：单一知识点

#### 教师示例：多个实验操作选项的独立核验

【题目压缩】
根据四幅操作图判断闻气味、滴加液体、取用药品、量筒读数中哪项操作正确。

【必要解析链】
每个选项分别调用一条课内操作规范：扇闻、滴管悬空、瓶塞倒放、视线与凹液面最低处水平；选项之间没有联合证据。

【教师档位】
基础题

【教师理由】
简单装置图，仪器使用操作和目的结合知识+应用

【边界说明】
不能降为送分题，因为要把操作规范应用到图示；不升中等题，因为四项是彼此独立的1层核验，不形成连续推理或共享模型。

【关键核心特征】
- reasoning_depth：1层
- knowledge_relation：单一知识点
- experiment_requirement：基础操作或读数
- evidence_relation：单一证据直接对应

## 难度3 — 中等题

### 核心判定依据

中等题是初中化学主力题型。纵向链深D通常包含实际3—4个有效化学决策，在`features.reasoning_depth`中通常填写“2-3层”；或者虽决策数较少，但需要严格辨析充分条件、证据边界、规范实验结论。学生需要把多个化学知识放进同一常规任务链，完成标准反应建模、完整实验流程、清晰联合证据、图表阶段对应或一套完整单方程式计算。方法仍是常规中考方法，但已经不是单一规则的直接套用。

整题任务负担B不能代替D：多个独立一步任务通常仍在基础题比较；但共享同一溶液组成、流程节点、反应条件、图表阶段或计算中间量时，必须沿任务边合并分析，不能拆成若干一步应用。

### 细粒度特征

- reasoning_depth通常为“2-3层”，reasoning_direction通常为“正向推导”。
- knowledge_relation常为“同模块简单关联”或“同模块深度关联”。
- evidence_relation可为“多条清晰证据联合”，但通常无需排除竞争解释。
- reaction_relation常为“单一直接反应”或“2-3个并列或简单连续反应”；calculation_model可为“单一方程式或关系式”。
- graph_table_requirement可为“多组比较归纳”；experiment_requirement可为“控制变量、现象解释或数据归纳”。
- subquestion_dependency可以是“多问共享模型但无答案依赖”；只要共享模型真实限制多个结论，就不能因答案没有直接复用而拆散。
- 通常无高阶共同约束，或只有一个显性约束；反应、图像和计算关系清晰，不需要竞争路径筛选。

以上是典型画像，不是feature计数器；单个高阶枚举不能机械决定档位。

### 最低进入门槛

至少真实出现以下之一：2—3层必要依赖、多个对象的联合证据比较、控制变量或数据归纳、完整单方程式计算。知识点多、小问多或材料长本身不满足门槛。

### 常见误判警示

- 常见高估：把标准曲线、常规方程式计算或清晰证据联合误称为图像反推、复杂守恒或方案评价。
- 常见高估：仅因出现“综合、实验、图像、流程、守恒、多个知识点”或实际只有一个显性约束，就判为拔高题。
- 常见低估：把完整计算拆成一次代入，或把联合比较拆成若干独立性质，从而压回基础题。
- 常见低估：忽略“前一节点决定后一节点”的任务边。例如组分判断决定方程式、反应先后决定产物、过量不足决定剩余物、图像阶段决定取哪段数据时，必须把整条常规链计入D。
- 对标准实验，若必须把操作、现象、多组数据和结论串联，通常属于中等题；不能拆成多个基础空。普通误差来源和常规故障分析本身不自动升拔高。
- 弱信号：多个化学式、多个反应名称、常规图表和多个独立小问不能单独触发本档。

### 与相邻档的否决条件

若核心理由只能写“一步应用、直接比例、逐项独立核验”，不得判中等题；若存在反应先后、共同约束、竞争解释、方案充分性或分段反推形成的明确卡点，则不能停在中等题。

### 代表性例题

#### 教师示例：联合比较三种气体燃烧产物

【题目压缩】
从观察颜色、闻气味、用燃着木条、检验燃烧产物中，选择能鉴别H₂、CO、CH₄的方法。

【必要解析链】
先确认三者均无色且燃烧火焰相近，再联合比较产物：H₂只生成水、CO只生成CO₂、CH₄同时生成水和CO₂，因此检验燃烧产物可区分。

【教师档位】
中等题

【教师理由】
常见气体的检验

【边界说明】
不能降为基础题，因为结论依赖三种对象及两类产物的联合比较；不升拔高题，因为证据清晰、路径常规，没有竞争解释或复杂约束。

【关键核心特征】
- reasoning_depth：2-3层
- reasoning_direction：正向推导
- knowledge_relation：同模块简单关联
- evidence_relation：多条清晰证据联合
- reaction_relation：2-3个并列或简单连续反应

#### 教师示例：单一方程式的完整常规计算

【题目压缩】
根据CH₄+2H₂O→4H₂+CO₂，计算16 g CH₄理论上生成H₂的质量并写出过程。

【必要解析链】
识别反应物与产物的化学计量关系，建立CH₄与H₂的质量关系，再代入16 g完成常规方程式计算。

【教师档位】
中等题

【教师理由】
单一化学方程式的不含杂质的纯计算

【边界说明】
不能降为基础题，因为需建立并完成一套完整化学方程式计算；不升拔高题，因为只有单反应、单路径，无杂质、阶段或联立。

【关键核心特征】
- reasoning_depth：2-3层
- reaction_relation：单一直接反应
- calculation_model：单一方程式或关系式
- constraint_complexity：单一约束

#### 教师示例：常规酸碱中和pH曲线

【题目压缩】
根据NaOH与稀盐酸反应的pH—时间曲线，判断滴加方向、恰好反应点溶质、酸过量点指示剂现象及曲线能否证明反应。

【必要解析链】
由起始pH>7判断原溶液为NaOH；b点pH=7对应恰好中和；c点pH<7对应酸过量；再逐项核验。

【教师档位】
中等题

【教师理由】
酸碱中和图像简单分析

【边界说明】
不能降为基础题，因为需把曲线三个阶段与反应状态连续对应；不升拔高题，因为阶段显性、模型标准，不需要隐藏拐点反推或竞争路径排除。

【关键核心特征】
- reasoning_depth：2-3层
- reasoning_direction：正向推导
- graph_table_requirement：多组比较归纳
- reaction_relation：单一直接反应
- unfamiliar_information_transfer：课内直接原型

## 难度4 — 拔高题

### 核心判定依据

拔高题通常包含实际5—6个有效化学决策，并存在一个明确、必要且会改变后续路径的区分度卡点；或者至少两项迁移/建模证据共同支持高阶判断。典型卡点包括逆向推理、反应先后、过量不足改变产物、共同约束、竞争解释排除、方案充分性评价、图像分段反推、流程物质去向或单一高阶定量。整体仍可沿一条有限主线解决，尚未形成多个高阶任务深度耦合的完整压轴模型。

单个量程、最大值、图像、装置名称、陌生物质或“守恒”关键词均不构成拔高门槛。必须说明卡点对应的任务边，以及若该节点判断错误会怎样改变后续答案。

### 细粒度特征

- reasoning_depth通常为“4-5层”，reasoning_direction可为“逆向推导”或“分类讨论或综合推导”。
- constraint_complexity常为“多个相互关联约束”，evidence_relation可达“需要排除竞争解释”。
- reaction_relation可为“多反应连续转化”“先后、竞争或过量不足”或“需要分情况判断的反应模型”。
- experiment_requirement可为“方案设计、评价或补充实验”；图表可达“拐点、平台或分段反推”。
- calculation_model可为“单一守恒或多反应计算”；只有出现多重守恒、差量、联立或分类并与其他高阶任务耦合时才进一步比较压轴题。
- subquestion_dependency常为“多问共享模型但无答案依赖”或“多问存在结果或任务链依赖”，但依赖类型必须用具体任务边证明。

以上是典型画像，不是feature计数器；单个高阶枚举不能机械决定档位。

### 最低进入门槛

必须能指出至少一个具体高阶卡点，并说明该卡点怎样改变判断路径；只有题型名称、陌生背景、流程图、多问或计算量，不能满足门槛。

### 常见误判警示

- 常见高估：看到工业流程、装置图、陌生物质或多小问就机械判拔高。
- 常见低估：把共享流程拆成独立小问，忽略条件、证据和定量对同一结论的共同限制。
- 常见低估：实验设计题只看到“检验某物质”，却没有审查对照、干扰排除、证据唯一性、装置先后和方案充分性；这些任务形成真实证据链时不能停在中等题。
- 常见低估：只看到“一个方程式”或“一次守恒”，没有继续检查组分判断、反应先后、过量不足、图像阶段、分项扣除或差量是否改变计算模型。
- 常见高估：标准课内模型只有常规正向3—4步，却因选项多、装置复杂或理由中出现“综合”被解释为决定性卡点。
- 弱信号：单纯跨模块、多个反应或一张复杂图片，若没有形成高阶卡点，不能单独触发本档。

### 与相邻档的否决条件

无法说清具体区分度卡点时不得判拔高题；若除杂、条件、装置、证据和定量已经形成多层嵌套且不可拆分的现场模型，则不得以“只有一个卡点”为由压在拔高题。

### 代表性例题

#### 教师示例：指定条件下的离子共存

【题目压缩】
判断四组离子能否在无色、酸性、pH=11或含大量Ba²⁺的指定溶液中大量共存。

【必要解析链】
分别把外部条件加入候选：无色排除MnO₄⁻；碱性使Fe³⁺沉淀；Ba²⁺与SO₄²⁻沉淀；只有酸性条件下给定离子不发生冲突。

【教师档位】
拔高题

【教师理由】
4个选项各有限定条件的离子共存判断

【边界说明】
不能降为中等题，因为每个候选同时受指定环境和离子反应规则共同限制，存在多组关联约束；不升压轴题，因为仍是课内离子反应的有限逐项判断，无多层嵌套模型。

【关键核心特征】
- reasoning_depth：4-5层
- reasoning_direction：分类讨论或综合推导
- constraint_complexity：多个相互关联约束
- reaction_relation：需要分情况判断的反应模型
- evidence_relation：需要排除竞争解释

#### 教师示例：实验方案的证据充分性评价

【题目压缩】
评价四个方案能否分别验证CaO与水反应放热、某气体为H₂、温度影响分子运动、CO₂与水反应。

【必要解析链】
逐项检查现象能否唯一支持目标；其中燃烧后出现水只能证明含氢，CH₄等竞争气体也会生成水，证据不足以唯一确认H₂。

【教师档位】
拔高题

【教师理由】
实验方案判断能量变化+气体检验+分子运动速率+二氧化碳性质探究

【边界说明】
不能降为中等题，因为必须评价证据充分性并排除竞争解释；不升压轴题，因为各方案仍是课内原型，彼此独立且无陌生模型或复杂定量。

【关键核心特征】
- reasoning_depth：4-5层
- experiment_requirement：方案设计、评价或补充实验
- evidence_relation：需要排除竞争解释
- constraint_complexity：多个相互关联约束

#### 教师示例：可沿单一主线解决的陌生工业流程

【题目压缩】
由含MnO₂、SiO₂、Fe₂O₃的软锰矿制MnCO₃：补写Fe³⁺被SO₂还原的分步方程式，判断滤液金属离子和被氧化物质，依据温度图选择浸锰温度，解释NH₄HCO₃温控并写沉淀反应。

【必要解析链】
沿同一流程依次使用已知反应→滤液组成→氧化还原→温度图→碳酸氢铵分解→沉淀方程式；各问共享流程，但大多可按明确节点逐步解决。

【教师档位】
拔高题

【教师理由】
工业流程含陌生方程式书写/多步反应机理/操作分析，跨模块知识点融合

【边界说明】
不能降为中等题，因为陌生方程式、流程组成、氧化还原和温控跨模块关联；不升压轴题，因为没有多杂质除去方案相互制约、热重模型或复杂定量联立，主线仍可顺序拆解。

【关键核心特征】
- reasoning_depth：4-5层
- knowledge_relation：跨模块融合
- reaction_relation：多反应连续转化
- graph_table_requirement：多组比较归纳
- subquestion_dependency：多问共享模型但无答案依赖
- unfamiliar_information_transfer：迁移后建立关系

#### 教师示例：课内实验原型上的高阶探究与定量卡点

【题目压缩】
围绕木炭还原CuO完成三阶段探究：解释加网罩和写方程式；用装置分别检验CO₂、CO并排除空气干扰；根据两种产物模型求CuO∶C质量比范围，并由10∶1反推同时生成CO和CO₂的总反应式。

【必要解析链】
先建立CO₂、CO两条反应模型及质量比边界，再判断混合产物范围；最后用质量守恒求两种气体比例并配出综合反应式。

【教师档位】
拔高题

【教师理由】
碳还原氧化铜实验探究+定量分析

【边界说明】
不能降为中等题，因为实验控制、气体证据、范围判断和定量反推形成明确卡点；不升压轴题，因为仍基于熟悉还原实验和有限两产物模型，没有完全陌生装置链或多层嵌套误差模型。

【关键核心特征】
- reasoning_depth：4-5层
- reaction_relation：需要分情况判断的反应模型
- experiment_requirement：方案设计、评价或补充实验
- calculation_model：单一守恒或多反应计算
- subquestion_dependency：多问存在结果或任务链依赖

## 难度5 — 压轴题

### 核心判定依据

压轴题形成完整高密度任务链：通常有6个及以上实际有效化学决策，或者至少两个高阶子任务通过物质、条件、证据、数据段或中间结论深度耦合，使任一局部判断都会改变后续模型。它可以表现为多模块深度融合、完全陌生模型现场建立、多层嵌套约束、多重守恒/差量/联立、多阶段实验与定量误差，或反应—证据—条件—图像—定量的整体耦合。

压轴结构是开放集合，不要求命中难度释义表中的某一条既有红线。释义表和代表性例题只提供已知锚点；只要任务图证明达到同等依赖深度、约束密度和模型建立负担，即使题型没有现成名称，也可以判为压轴题。反之，列出多个高阶词语但没有任务边，不能判压轴。

### 细粒度特征

- reasoning_depth常为“6层及以上”，但教师确认的特殊同构结构可以例外，不能机械计层。
- knowledge_relation常为“多模块深度融合”，constraint_complexity常为“多层嵌套约束”。
- calculation_model常为“多重守恒、差量、联立或分类”，或实验任务达到“多阶段探究与定量误差”。
- unfamiliar_information_transfer可为“完全陌生模型现场建立”，subquestion_dependency常为“多问存在结果或任务链依赖”。
- 可以不同时命中全部典型特征；决定性依据是完整任务链的不可拆分性，而不是“红线计数”。
- 图片中的流程空间关系、装置连接、曲线分段、表格对应和多区域联动必须参与任务图；只提取文本中没有的OCR文字不足以判断本档。

以上是典型画像，不是feature计数器；单个高阶枚举不能机械决定档位。

### 最低进入门槛

至少指出一条完整压轴链，并说明局部任务怎样互相改变模型或答案；只列举高阶特征名称不算触发。即使难度释义表没有同题型示例，只要真实依赖达到完整压轴结构，也可进入本档。

### 常见误判警示

- 常见高估：看到陌生、项目、流程、混合物、守恒或多问即判压轴。
- 常见低估：逐小问看见常规步骤后，忽略它们共享原料组成、除杂目标、温控、安全或取样倍数而形成整链。
- 常见低估：只以“是否命中某条压轴红线”作必要条件，导致未被释义表穷举的新型压轴结构被压回4档。
- 常见低估：最终定档只读取局部图片差异，没有看到图片的整体流程、装置、图表阶段如何串联文字条件。必须说明至少两条跨区域或跨小问任务边。
- 常见低估：把连续定量拆成“一个方程式+一次守恒”。若组分判断决定反应式、先后/过量决定产物、图像阶段决定数据、差量/联立决定最终量，它们共同构成压轴链。
- 常见高估：多个模块只是并列出现、每问可以独立作答，或只有一个有限高阶卡点时，应保持拔高题比较。
- 弱信号：单一高阶卡点、有限多反应、普通单守恒或题目篇幅大，均不能单独触发压轴题。

### 与相邻档的否决条件

不能指出完整压轴结构或不可拆分任务链时不得判压轴题；已确认多层嵌套、现场建模或多重定量耦合时，不得因每个局部步骤看似常规而压回拔高题。

### 代表性例题

#### 教师示例：部分变质中的守恒与差量连续计算

【题目压缩】
13.3 g长期露置的NaOH固体与150 g、7.3%的盐酸恰好反应，求已变质与未变质NaOH质量比。

【必要解析链】
先由盐酸用量和钠元素守恒反推出原NaOH总量；再把固体增重视为NaOH吸收CO₂生成Na₂CO₃的差量，求已变质量；最后由混合物质量扣出未变质量并求比。

【教师档位】
压轴题

【教师理由】
选择题-复杂反应过程+计算

【边界说明】
不能降为拔高题，因为原料组成判断、多个反应、元素守恒和差量前后不可拆分，前一步改变后续模型；已是最高档。

【关键核心特征】
- reasoning_depth：6层及以上
- reaction_relation：多反应连续转化
- calculation_model：多重守恒、差量、联立或分类
- constraint_complexity：多层嵌套约束
- representation_conversion：宏观-微观-符号-定量多重转换

#### 教师示例：多杂质制备流程与热重条件深耦合

【题目压缩】
以含ZnO、PbO、CuO、FeO、Fe₂O₃、SiO₂的锌灰制四水合磷酸锌：写浸取反应，选择不引杂的pH调节剂，选择置换除Cu²⁺试剂并写反应，确定分离操作，再由热重图选择获得两种水合物混合产品的温区并判断变化类型。

【必要解析链】
先按杂质去向确定滤渣和溶液；调pH时还要避免引入新杂质并服务最终含锌产品；除铜试剂同样受产品组成约束；最后把热重平台与水合物组成、烘干目标关联。

【教师档位】
压轴题

【教师理由】
自主招生工业流程，含除杂/方程式/操作条件控制，跨模块综合

【边界说明】
不能降为拔高题，因为除杂、试剂选择、pH控制、后续制备和热重产品目标相互制约，不能拆成单一路径；已是最高档。

【关键核心特征】
- reasoning_depth：6层及以上
- knowledge_relation：多模块深度融合
- constraint_complexity：多层嵌套约束
- reaction_relation：多反应连续转化
- graph_table_requirement：拐点、平台或分段反推
- subquestion_dependency：多问存在结果或任务链依赖

#### 教师示例：陌生SnCl₄制备、装置控制与纯度测定

【题目压缩】
依据Sn、SnCl₂、SnCl₄的熔沸点及SnCl₄遇水反应信息，设计熔融Sn与有毒Cl₂制无水SnCl₄：判断导管、洗气、冷凝、防水和尾气装置功能，确定避免SnCl₂混入的温区，写水解反应，再由取样稀释和AgNO₃沉淀数据计算纯度。

【必要解析链】
由陌生物性确定发生、分离和防水条件→由气体毒性和副产物确定洗气/尾气安全→由熔沸点建立温控窗口→由水解生成HCl与AgNO₃沉淀建立4∶1定量链并处理取样倍数。

【教师档位】
压轴题

【教师理由】
含陌生反应/装置功能分析/温度控制/纯度计算

【边界说明】
不能降为拔高题，因为装置、物性、温控、防水、安全和纯度计算共同构成现场模型，局部步骤常规但整链不可拆分；已是最高档。

【关键核心特征】
- reasoning_depth：6层及以上
- knowledge_relation：多模块深度融合
- experiment_requirement：多阶段探究与定量误差
- unfamiliar_information_transfer：完全陌生模型现场建立
- calculation_model：单一守恒或多反应计算
- subquestion_dependency：多问存在结果或任务链依赖

#### 教师示例：固定基团约束下的特殊转换关系

【题目压缩】
FeSO₄与Fe₂(SO₄)₃任意混合，已知铁元素质量分数为a%，求硫元素质量分数。

【必要解析链】
识别两种盐的非铁部分都由SO₄组成；总的S与O质量比始终为1∶2；由非铁元素总质量分数1-a%直接按固定基团比例分配得到S占其中三分之一。

【教师档位】
压轴题

【教师理由】
转换关系法的应用

【边界说明】
教师将该固定基团转换关系判为压轴；只对共同基团约束和转换结构真正同构的新题有效。普通固定比例、单一守恒或一般混合物计算不得据此外推到压轴。

【关键核心特征】
- reasoning_depth：4-5层
- reasoning_direction：逆向推导
- representation_conversion：宏观-微观-符号-定量多重转换
- calculation_model：单一方程式或关系式
- unfamiliar_information_transfer：迁移后建立关系

## 五、相邻档位边界校准 few-shot

这些示例来自真实题库边界类型，用于校准相邻档位。示例只给题目摘要与判定逻辑，不改变后面的JSON输出格式。不要记忆题目名词，应迁移其结构。题型、篇幅、图片、对象、选项和小问数量都不能替代边界判断。

边界执行顺序：

1. 先在`reasoning.core_basis`写出实际有效化学决策数D和整题任务负担B；
2. 再写出关键任务边，例如“组分判断→方程式选择→定量模型”或“图像阶段→反应状态→数据选择”；
3. 只比较包含最终档位的相邻边界，`why_not_lower`和`why_not_higher`不得跨两档；
4. 若理由只能依靠题型名称、图片复杂、选项多、小问多或关键词，则证据不足，回到较低档；
5. 若多个局部步骤通过物质、条件、证据或中间量相互改变，必须按整链判断，不能用“每一步都常规”压档。

### 送分题 vs 基础题

【边界示例1】
题目摘要：选择属于化学性质的一项：导电性、可燃性、延展性、挥发性。
最终等级：送分题。
核心特征：reasoning_depth=0层，reasoning_direction=直接识记，knowledge_relation=单一知识点，reaction_relation=无反应关系，evidence_relation=无证据任务。
判定理由：直接识别“可燃性”必须通过化学变化表现；其余三项是熟悉的物理性质。不需要由题设形成中间结论。 知识点纯识记，描述化学性质的词直接判断
为什么不更低：送分题已经是最低档。
为什么不更高：看到熟悉性质词即可直接分类，没有生活情境映射、模型转换或由条件推出新结论；选项数量不构成应用步骤。

【边界示例2】
题目摘要：柠檬汁能使石蕊试液变红，判断柠檬汁显酸性、碱性、中性或无法确定。
最终等级：基础题。
核心特征：reasoning_depth=1层，reasoning_direction=正向推导，knowledge_relation=单一知识点，evidence_relation=单一证据直接对应，unfamiliar_information_transfer=课内直接原型。
判定理由：调用“石蕊遇酸变红”规则，把已给现象转换为“柠檬汁显酸性”的结论。 酸碱指示剂性质，由石蕊变红推断柠檬汁显酸性
为什么不更低：必须把“石蕊变红”转换为“溶液显酸性”，答案不是题面原词的直接再现。
为什么不更高：只有一条显性规则和一次实质转换，没有联合证据、连续反应、实验归纳或完整计算模型。

边界总结：送分与基础的界线不是字面上的“是否做了一步”，而是是否需要自主选择规律、生成中间结论或切换不同回答规则。熟悉类别的一次透明映射仍可为送分题；相同规则重复不升档；多个不同规则形成的B不能被压成一个直接检索束。

### 基础题 vs 中等题

【边界示例3】
题目摘要：根据四幅操作图判断闻气味、滴加液体、取用药品、量筒读数中哪项操作正确。
最终等级：基础题。
核心特征：reasoning_depth=1层，knowledge_relation=单一知识点，experiment_requirement=基础操作或读数，evidence_relation=单一证据直接对应。
判定理由：每个选项分别调用一条课内操作规范：扇闻、滴管悬空、瓶塞倒放、视线与凹液面最低处水平；选项之间没有联合证据。 简单装置图，仪器使用操作和目的结合知识+应用
为什么不更低：需要把每条操作规范应用到对应图示，不是一个直接检索束。
为什么不更高：四个选项彼此独立，每项只有一条规范和一次核验；没有共享中间结论、完整实验流程或2—3层连续依赖。

【边界示例4】
题目摘要：从观察颜色、闻气味、用燃着木条、检验燃烧产物中，选择能鉴别H₂、CO、CH₄的方法。
最终等级：中等题。
核心特征：reasoning_depth=2-3层，reasoning_direction=正向推导，knowledge_relation=同模块简单关联，evidence_relation=多条清晰证据联合，reaction_relation=2-3个并列或简单连续反应。
判定理由：先确认三者均无色且燃烧火焰相近，再联合比较产物：H₂只生成水、CO只生成CO₂、CH₄同时生成水和CO₂，因此检验燃烧产物可区分。 常见气体的检验
为什么不更低：必须同时比较三种对象及水、二氧化碳两类产物，单独套用一条性质不能唯一完成鉴别。
为什么不更高：联合证据清晰且属于课内常规反应，不需要排除复杂竞争路径、设计新方案或处理多层约束。

【边界示例5】
题目摘要：根据CH₄+2H₂O→4H₂+CO₂，计算16 g CH₄理论上生成H₂的质量并写出过程。
最终等级：中等题。
核心特征：reasoning_depth=2-3层，reaction_relation=单一直接反应，calculation_model=单一方程式或关系式，constraint_complexity=单一约束。
判定理由：识别反应物与产物的化学计量关系，建立CH₄与H₂的质量关系，再代入16 g完成常规方程式计算。 单一化学方程式的不含杂质的纯计算
为什么不更低：需要建立方程式中的完整化学计量关系并完成计算，不是已给比例的一次代入。
为什么不更高：只有单反应、单路径，无杂质、反应先后、分段图像、多重守恒或联立。

边界总结：基础题可以有多个独立的一步核验；中等题必须出现实际3—4个有效决策、2—3层连续依赖、共享模型、联合证据、完整实验流程或完整常规模型。多空、多知识点和标准流程本身不升档；组分、反应、图像或中间量真实决定后续路径时也不得拆散压档。

### 中等题 vs 拔高题

【边界示例6】
题目摘要：根据NaOH与稀盐酸反应的pH—时间曲线，判断滴加方向、恰好反应点溶质、酸过量点指示剂现象及曲线能否证明反应。
最终等级：中等题。
核心特征：reasoning_depth=2-3层，reasoning_direction=正向推导，graph_table_requirement=多组比较归纳，reaction_relation=单一直接反应，unfamiliar_information_transfer=课内直接原型。
判定理由：由起始pH>7判断原溶液为NaOH；b点pH=7对应恰好中和；c点pH<7对应酸过量；再逐项核验。 酸碱中和图像简单分析
为什么不更低：要把起始、中和和酸过量三个阶段与pH曲线连续对应，超过一次显性应用。
为什么不更高：曲线模型标准、阶段显性，只需常规正向顺推；没有隐藏阶段反推、共同约束或决定性转换。

【边界示例7】
题目摘要：判断四组离子能否在无色、酸性、pH=11或含大量Ba²⁺的指定溶液中大量共存。
最终等级：拔高题。
核心特征：reasoning_depth=4-5层，reasoning_direction=分类讨论或综合推导，constraint_complexity=多个相互关联约束，reaction_relation=需要分情况判断的反应模型，evidence_relation=需要排除竞争解释。
判定理由：分别把外部条件加入候选：无色排除MnO₄⁻；碱性使Fe³⁺沉淀；Ba²⁺与SO₄²⁻沉淀；只有酸性条件下给定离子不发生冲突。 4个选项各有限定条件的离子共存判断
为什么不更低：每个候选都要同时接受指定环境和离子反应规则的共同约束，普通正向逐项判断不足以完成。
为什么不更高：约束数量有限且都来自课内离子反应，不需要现场建立陌生模型、多层嵌套或复杂定量。

【边界示例8】
题目摘要：评价四个方案能否分别验证CaO与水反应放热、某气体为H₂、温度影响分子运动、CO₂与水反应。
最终等级：拔高题。
核心特征：reasoning_depth=4-5层，experiment_requirement=方案设计、评价或补充实验，evidence_relation=需要排除竞争解释，constraint_complexity=多个相互关联约束。
判定理由：逐项检查现象能否唯一支持目标；其中燃烧后出现水只能证明含氢，CH₄等竞争气体也会生成水，证据不足以唯一确认H₂。 实验方案判断能量变化+气体检验+分子运动速率+二氧化碳性质探究
为什么不更低：必须检验现象是否唯一支持目标，并用其他可能气体反驳证据充分性；不是普通实验现象对应。
为什么不更高：各方案仍是课内原型且彼此独立，没有多阶段任务依赖、陌生装置建模或定量误差链。

边界总结：中等题是常规正向分析；拔高题通常需要实际5—6个有效决策，并有一个决定性高阶卡点或至少两项迁移/建模证据共同支持。实验方案必须审查证据唯一性与干扰，定量题必须审查反应先后、过量、图像阶段和守恒模型；但单个图像、最大值、装置或陌生名称不能升档。

### 拔高题 vs 压轴题

【边界示例9】
题目摘要：由含MnO₂、SiO₂、Fe₂O₃的软锰矿制MnCO₃：补写Fe³⁺被SO₂还原的分步方程式，判断滤液金属离子和被氧化物质，依据温度图选择浸锰温度，解释NH₄HCO₃温控并写沉淀反应。
最终等级：拔高题。
核心特征：reasoning_depth=4-5层，knowledge_relation=跨模块融合，reaction_relation=多反应连续转化，graph_table_requirement=多组比较归纳，subquestion_dependency=多问共享模型但无答案依赖，unfamiliar_information_transfer=迁移后建立关系。
判定理由：沿同一流程依次使用已知反应→滤液组成→氧化还原→温度图→碳酸氢铵分解→沉淀方程式；各问共享流程，但大多可按明确节点逐步解决。 工业流程含陌生方程式书写/多步反应机理/操作分析，跨模块知识点融合
为什么不更低：陌生方程式、流程组成、氧化还原和温控跨模块关联，形成明确流程分析卡点。
为什么不更高：各问仍可沿一条主流程逐节点解决；没有多杂质除去方案相互制约、热重产品目标或复杂定量联立。

【边界示例10】
题目摘要：以含ZnO、PbO、CuO、FeO、Fe₂O₃、SiO₂的锌灰制四水合磷酸锌：写浸取反应，选择不引杂的pH调节剂，选择置换除Cu²⁺试剂并写反应，确定分离操作，再由热重图选择获得两种水合物混合产品的温区并判断变化类型。
最终等级：压轴题。
核心特征：reasoning_depth=6层及以上，knowledge_relation=多模块深度融合，constraint_complexity=多层嵌套约束，reaction_relation=多反应连续转化，graph_table_requirement=拐点、平台或分段反推，subquestion_dependency=多问存在结果或任务链依赖。
判定理由：先按杂质去向确定滤渣和溶液；调pH时还要避免引入新杂质并服务最终含锌产品；除铜试剂同样受产品组成约束；最后把热重平台与水合物组成、烘干目标关联。 自主招生工业流程，含除杂/方程式/操作条件控制，跨模块综合
为什么不更低：除杂、试剂不引杂、pH控制、后续含锌产品和热重温区相互制约，已超过单一流程卡点。
为什么不更高：压轴题已经是最高档。

【边界示例11】
题目摘要：围绕木炭还原CuO完成三阶段探究：解释加网罩和写方程式；用装置分别检验CO₂、CO并排除空气干扰；根据两种产物模型求CuO∶C质量比范围，并由10∶1反推同时生成CO和CO₂的总反应式。
最终等级：拔高题。
核心特征：reasoning_depth=4-5层，reaction_relation=需要分情况判断的反应模型，experiment_requirement=方案设计、评价或补充实验，calculation_model=单一守恒或多反应计算，subquestion_dependency=多问存在结果或任务链依赖。
判定理由：先建立CO₂、CO两条反应模型及质量比边界，再判断混合产物范围；最后用质量守恒求两种气体比例并配出综合反应式。 碳还原氧化铜实验探究+定量分析
为什么不更低：气体证据、范围判断和定量反推形成一个明确的高阶实验定量卡点。
为什么不更高：核心仍是熟悉还原实验和有限两产物模型，没有完全陌生装置链、多层安全条件或不可拆分的多模块现场建模。

【边界示例12】
题目摘要：依据Sn、SnCl₂、SnCl₄的熔沸点及SnCl₄遇水反应信息，设计熔融Sn与有毒Cl₂制无水SnCl₄：判断导管、洗气、冷凝、防水和尾气装置功能，确定避免SnCl₂混入的温区，写水解反应，再由取样稀释和AgNO₃沉淀数据计算纯度。
最终等级：压轴题。
核心特征：reasoning_depth=6层及以上，knowledge_relation=多模块深度融合，experiment_requirement=多阶段探究与定量误差，unfamiliar_information_transfer=完全陌生模型现场建立，calculation_model=单一守恒或多反应计算，subquestion_dependency=多问存在结果或任务链依赖。
判定理由：由陌生物性确定发生、分离和防水条件→由气体毒性和副产物确定洗气/尾气安全→由熔沸点建立温控窗口→由水解生成HCl与AgNO₃沉淀建立4∶1定量链并处理取样倍数。 含陌生反应/装置功能分析/温度控制/纯度计算
为什么不更低：必须由陌生物性同时建立装置、温控、防水、安全和纯度测定模型，前段条件会改变后段任务。
为什么不更高：压轴题已经是最高档。

边界总结：4档是有限主线上的单一高阶卡点；5档是通常6个及以上有效决策，或多个高阶任务互相改变模型、形成不可拆分的完整链。5档判据是开放的结构标准，不以命中既有红线为必要条件；同时必须证明至少两条关键任务边，不能把并列模块机械聚合成压轴题。

### 特殊压轴教师口径：只允许真同构

【边界示例13】
题目摘要：FeSO₄与Fe₂(SO₄)₃任意混合，已知铁元素质量分数为a%，求硫元素质量分数。
最终等级：压轴题。
核心特征：reasoning_depth=4-5层，reasoning_direction=逆向推导，representation_conversion=宏观-微观-符号-定量多重转换，calculation_model=单一方程式或关系式，unfamiliar_information_transfer=迁移后建立关系。
判定理由：识别两种盐的非铁部分都由SO₄组成；总的S与O质量比始终为1∶2；由非铁元素总质量分数1-a%直接按固定基团比例分配得到S占其中三分之一。 转换关系法的应用
为什么不更低：教师确认该固定基团约束与整体转换结构属于压轴口径，不能按普通单关系式计算压低。
为什么不更高：压轴题已经是最高档。

防外推：新题必须具有共同基团不变、整体剩余质量按固定组成拆分的真正同构转换。普通固定比例、单一守恒、一般混合物计算或“转换关系”字样不得据此判压轴。

## 六、题型结构复核（只作任务识别，不按题型定档）
================================================================================

- 化学用语与微观：直接符号识记为1档候选；一步化合价/化学式转换为2档候选；宏观—微观—符号联合为3档以上候选。
- 实验：仪器和规范原文为1档候选；一步装置选择为2档候选；控制变量和数据归纳为3档候选；方案评价、补充实验、竞争解释排除为4档候选；多阶段探究与定量误差为5档候选。
- 鉴别、除杂、推断：单现象直接识别为2档候选；常见2-3层正向转化为3档候选；无试剂顺序、滤渣滤液、变质探究、方案缺陷为4档候选；多组分、多证据冲突与定量深耦合为5档候选。
- 酸碱盐与金属：单一性质为1-2档候选；同模块常规综合为3档候选；先后反应、过量不足、滤渣滤液、离子条件联合为4档候选；多阶段反应与守恒、图像、方案深耦合为5档候选。
- 工艺流程：按箭头直接填写为2-3档候选；理解基本流程目的为3档候选；试剂顺序、循环、滤渣滤液和产率共同限制为4档候选；陌生流程叠加多反应、定量、误差和评价为5档候选。
- 图像表格：直接读数为2档候选；多组比较为3档候选；隐藏拐点、平台和阶段反推为4档候选；多图像与反应、守恒、分类耦合为5档候选。
- 定量：直接比例为2档候选；单一方程式或关系式为3档候选；连续反应、阶段图像或单一高阶守恒为4档候选；多组分、多重守恒、差量、联立、范围为5档候选。

这些仅是候选范围。最终必须回到12个核心特征与相邻边界，不能按题型名称直接映射。

## 七、输出前强制自检
================================================================================

1. 是否先读完两张图片并重建完整题面，而不是只读OCR文字？
2. 是否区分独立小问、共享模型与结果依赖？
3. 是否选择最高难任务并只对其完整依赖链提取顶层特征？
4. 是否把图片版式、选项、空、方程式或操作数量误当难度？
5. 是否把普通直接识图错误解释成一步应用？
6. 是否把选择题排除错误选项错误解释成竞争证据排除？
7. 是否把独立反应累计成连续反应？过量不足是否真的改变后续判断？
8. 若判3档，是否至少有两项中等结构共同支持？
