# Chemistry V6 decoupled task-graph A1 design notes

## What is accepted from the external review

The review correctly identifies the primary architectural defect in V6:
Evidence-15 is simultaneously an intermediate representation, a difficulty
classifier, an explanation format, and a postprocessing trigger.  An early
semantic error can therefore produce a schema-valid, internally consistent,
but question-grounding-invalid feature bundle and level.

The V6 decoupled task-graph A1 candidate implements these accepted changes:

1. The teacher-facing primary difficulty decision is made before task-graph
   audit output.
2. Evidence-15 and `coarse_difficulty` are removed from the model contract.
3. The model emits concrete task nodes and dependency edges rather than a
   self-reported abstract depth enum.
4. The schema computes node count, edge count, longest dependency path and
   cross-subquestion edge count deterministically.
5. Both lower and upper adjacent boundaries are represented explicitly.
6. `can_rate`, readability, missing-information and input-conflict fields are
   first-class output.  An unrateable item is logged as a failure rather than
   forced into one of five levels.
7. Image input is grounded by full structured stem, options, analysis and
   subquestion text.  Images remain available for formula, diagram, graph and
   spatial information.
8. Representative examples use one consistent format and appear once each.
9. The first A1 experiment disables automatic level changes.  It isolates the
   prompt architecture before any new postprocessing rule is approved.

## Points accepted with qualifications

### Postprocessing did not always amplify an error

It is accurate that V6 postprocessing reuses correlated model evidence and did
not improve repeat-run stability.  It is too broad to say it always amplifies
the initial error: all 86 diagnosed feature-extraction errors were unchanged
by postprocessing.  The precise issue is lack of independent corrective
evidence; depending on the gate, the result may be no-op, correction, or harm.

### `entry_operation` is not logically impossible, but its scope is ambiguous

The old field was intended to describe entry into the highest difficult task,
not necessarily the first chronological action in the whole solution.  The
review's complex-task counterexample therefore does not prove the concept is
invalid.  It does show that the name, scope and forced mapping to total depth
are unsafe.  A1 removes the field rather than trying to repair that ambiguity.

### Full text should ground, not replace, images

The review correctly identifies image-only structure reconstruction as a
variance amplifier.  It would be unsafe to discard images because chemistry
formulae, apparatus, arrows, tables and graph regions can be lost or corrupted
in structured text.  A1 sends both sources and requires conflict reporting.

## Points not accepted literally

### Not every semantic feature can be generated by code

Code can derive graph topology, but it cannot infer from topology alone
whether an alternative chemical explanation is genuinely viable, whether an
experiment proves a conclusion, or whether an unfamiliar relation constitutes
substantive transfer.  A1 keeps these as question-grounded prose in the five
primary dimensions.  It does not convert them into pseudo-objective numeric
features.

### A task graph is auditable evidence, not an independent oracle

The task graph is still model-generated and may omit or invent nodes and
edges.  It improves inspectability and enables deterministic graph metrics,
but it does not by itself guarantee a correct level.  For that reason A1 does
not automatically overwrite the independently chosen level from graph size.
Level/graph tension is only flagged for later audit.

### Prompt wording cannot prove hidden cognitive stage separation

The review is correct that natural-language instructions cannot make an LLM
execute independently verifiable internal phases.  A1 therefore does not claim
to control hidden reasoning order.  Its enforceable separation is external:
the primary level appears before the task graph in the output contract, the
schema never calculates a level from graph size, and postprocessing does not
automatically replace that level.  Repeat-run experiments must determine
whether this reduces practical coupling.

### Objective features may still support future rules

The correct conclusion is not that all features must be ignored forever.
Observable, repeatedly stable evidence can support a narrow adjacent rule.
Such a rule must demonstrate positive net contribution on reviewed labels and
must improve or preserve repeat-run stability.  It is intentionally absent
from the first A1 experiment.

### Inconsistent teacher exceptions should not become prompt rules

When a teacher label assigns level 5 to a structure that otherwise matches the
general level-4 standard, adding a named "special isomorphism" exception makes
the classifier less general and cannot be recovered from objective features.
A1 omits such exceptions.  They should first enter teacher-label review; only a
generalizable structural distinction belongs in the prompt.

## First-experiment acceptance criteria

A1 should not be promoted merely for improving one-run accuracy.  Compare it
with the frozen V6 baseline on the same 591 questions and report:

1. raw and strict accuracy against teacher labels;
2. raw and strict accuracy against the reviewed diagnostic labels;
3. failure and `can_rate=false` counts;
4. same-question repeat-run level agreement;
5. exact task-graph agreement and per-field/input-assessment agreement;
6. confusion pairs for all four adjacent boundaries;
7. graph/level tension flags and their precision under manual review;
8. token cost and runtime.

No automatic postprocessor should be added until the raw architecture has been
run at least twice and the candidate rule is validated against independent,
reviewed evidence.
